# Oscilloscope USB Control
This repository contains various lines of codes for controlling a Tekronix MSO 2012 oscilloscope.

#### MSO 2012 - Specification
Bandwidth: 100 MHz
Analog channels: 2
Rise time: 3.5 ns
Sample rate: 1 GS/s
Record length: 1 MPoint
Vertical resolution: 8 bits
Input impedance: 1 MΩ ±2%, 11.5 pF ±2 pF
Input sensitivity range: 2 mV/div to 5 V/div
Digital channels: 16
Threshold selections: TTL, CMOS, ECL, PECL, and user defined (±20 V)
Digital input voltage range: ±40 V
